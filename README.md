# Орбита — магазин телескопов

Интернет-магазин телескопов: Laravel REST API + Vue 3 (Vite) + Tailwind CSS v4.

## Быстрый запуск

1. Убедитесь, что установлены **Node.js 20+**, **PHP 8.2+** и **XAMPP** (MariaDB/MySQL).
2. Дважды щёлкните `start-project.bat`.
3. Дождитесь сообщения «Project is running» — браузер откроется автоматически.

| Что | Адрес |
| --- | --- |
| Сайт | http://127.0.0.1:5173 |
| API | http://127.0.0.1:8000/api/v1 |
| Админ-панель Voyager | http://127.0.0.1:8000/admin |

Данные администратора: `admin@orbita.by` / `admin12345`.

Остановка всех служб: `stop-project.bat` (MariaDB останавливается вместе с ними).
`stop-project.bat keepdb` оставляет базу данных запущенной.

Скрипты можно запускать по отдельности:

- `start-backend.bat` — MariaDB, миграции и Laravel API на порту 8000;
- `start-frontend.bat` — Vite на порту 5173.

## Страницы сайта

| Маршрут | Что на странице |
| --- | --- |
| `/` | Главная: hero с градиентными свечениями, преимущества, подборки, отзывы, FAQ и призывы к действию |
| `/catalog` | Каталог: фильтры по категории, типу оптики, цене и наличию, поиск, сортировка, пагинация, карточки товаров |
| `/cart` | Корзина: количество и лимиты по складу, итог, способ получения, контактные данные и подтверждение заказа |
| `/selection` | Подбор телескопа: пошаговый мастер из четырёх шагов с прогрессом, проверкой полей и персональной рекомендацией |
| `/services` | Услуги и тарифы: пакеты обслуживания, доставка, гарантия, рассрочка, частые вопросы |
| `/about` | О магазине: история, принципы, команда, показатели |
| `/support` | Поддержка: мессенджер с диалогами и автоответом, контакты, FAQ |
| `/login`, `/register` | Вход и регистрация с валидацией полей и состояниями ошибок |
| `/forgot-password`, `/password-reset` | Восстановление пароля |
| `/admin` | Обзор магазина: показатели, график продаж, последние заказы |
| `/admin/orders` | Заказы: Kanban-доска со сменой статуса; новые заказы с сайта появляются в колонке «Новые» |
| `/admin/products` | Товары: таблица с созданием, редактированием и удалением |
| `/admin/import` | Импорт товаров из Excel (SheetJS) с предпросмотром |
| `/admin/files` | История загруженных файлов |

Разделы `/admin*` доступны после входа и используют общий layout с боковым меню.
Неизвестные адреса показывают страницу 404.

Корзина работает на фронтенде: позиции хранятся в `localStorage` (`orbita-cart`),
а оформление на `/cart` — демонстрационное, без записи заказа в базу. Оформленный
заказ сохраняется в `orbita-orders` и появляется на доске `/admin/orders`
в колонке «Новые» (вместе с демо-заказами). Статусы карточек тоже сохраняются
в браузере.

## Структура

```
backend/                    Laravel API, миграции, Voyager
frontend/                   Vue 3 SPA
  src/style.css             Tailwind, @theme-токены, @utility, light/dark
  src/styles/components.css компонентный слой (@layer components)
  src/components/           навбар, футер, карточки, модальное окно, admin shell
  src/composables/          useTheme — тема и localStorage
  src/views/                страницы сайта
  src/views/admin/          разделы панели управления
start-*.bat                 запуск проекта
stop-project.bat            остановка проекта
docs/                       пояснительная записка
```

## Темы и оформление

Светлая и тёмная темы переключаются кнопкой в навбаре: выбор хранится в
`localStorage` под ключом `orbita-theme`, а inline-скрипт в `index.html`
применяет его до первой отрисовки. Семантические токены в `@theme` позволяют
всем страницам получать светлые поверхности без дублирования классов.

Цены выводятся компонентом `PriceTag` с фирменным знаком валюты из шрифта
`Untitled1`; текстовое «руб.» доступно скринридерам.

## Стек

- **Vue 3** (`<script setup>`), **Vue Router**, **Pinia**, **Axios**;
- **Tailwind CSS v4** через официальный плагин `@tailwindcss/vite` (без CDN);
- **Laravel** + **Sanctum** для REST API и авторизации;
- **SheetJS (xlsx)** для импорта товаров из Excel в браузере.

Дизайн-токены (цвета, шрифты, радиусы, тени, контейнер и отступы) находятся в
`frontend/src/style.css` в блоке `@theme`. В разметке используются утилитарные
классы Tailwind и их варианты (`sm:`, `md:`, `lg:`, `xl:`, `hover:`, `focus:`,
`active:`, `disabled:`, `group-*`, `peer-*`, `data-*`).

Подробнее о выборе Tailwind и сравнении с Bootstrap — в
[`docs/TAILWIND_VS_BOOTSTRAP.md`](docs/TAILWIND_VS_BOOTSTRAP.md).

## Сборка фронтенда

```bat
cd frontend
npm.cmd install
npm.cmd run build
```

Готовые файлы появятся в `frontend/dist`.

## Публикация

Сайт опубликован на **Cloudflare Pages** (Free). Настройки сборки в дашборде:

| Параметр | Значение |
| --- | --- |
| Root directory | `frontend` |
| Build command | `npm run build` |
| Build output directory | `dist` |
| Переменная окружения | `NODE_VERSION=22` |

Production-сборка без переменной `VITE_API_URL` работает автономно: `src/api/http.js`
подключает демо-адаптер (`src/api/demo.js`, `src/data/demoCatalog.js`) вместо Laravel.
Каталог, фильтры, подбор, корзина и оформление заказа остаются рабочими, заказы
хранятся в `localStorage`. В dev-режиме (`npm.cmd run dev`) запросы по-прежнему идут
в реальный API, поэтому локальная версия с Laravel и админкой не меняется.

Для SPA-маршрутов ничего настраивать не нужно: Cloudflare Pages с пресетом Vite сам отдаёт `index.html` на внутренние адреса.

Рекламные плейсхолдеры — компонент `frontend/src/components/AdSlot.vue`: баннер
на главной под популярными товарами и блок в сайдбаре каталога (на десктопе).

Сравнение хостингов, риски политик и обоснование выбора — в
[`docs/HOSTING_REPORT.md`](docs/HOSTING_REPORT.md). Скриншоты блоков —
в `docs/screenshots/`.
